# 🧮 简易计算机智能体

一个功能强大的简易计算机智能体，支持命令行和图形界面两种模式。

## ✨ 功能特点

- 🎯 **双模式运行**: 支持命令行模式 (CLI) 和图形界面模式 (GUI)
- 📊 **数学计算**: 支持多种数学函数和运算
- 🎨 **美观界面**: 深色主题的图形界面设计
- 📖 **帮助文档**: 详细的函数使用说明

## 🚀 快速开始

### 安装依赖

```bash
# 无需额外依赖，使用 Python 内置库
```

### 运行方式

```bash
python simple_calculator_agent.py
```

启动后选择运行模式：
- `1`: 命令行模式
- `2`: 图形界面模式

## 📐 支持的数学函数

### 基本运算
- `+`, `-`, `*`, `/` - 加减乘除
- `pow(x, y)` - x的y次方

### 三角函数
- `sin(x)`, `cos(x)`, `tan(x)` - 正弦、余弦、正切
- `asin(x)`, `acos(x)`, `atan(x)` - 反正弦、反余弦、反正切

### 双曲函数
- `sinh(x)`, `cosh(x)`, `tanh(x)` - 双曲正弦、余弦、正切

### 对数函数
- `log(x)` - 自然对数
- `log10(x)` - 常用对数
- `log2(x)` - 以2为底的对数

### 其他函数
- `sqrt(x)` - 平方根
- `exp(x)` - e的x次方
- `abs(x)` - 绝对值
- `floor(x)` - 向下取整
- `ceil(x)` - 向上取整
- `round(x)` - 四舍五入
- `factorial(x)` - 阶乘

### 常数
- `pi` - 圆周率
- `e` - 自然常数

## 📝 使用示例

```bash
# 命令行模式示例
> 2 + 3 * 4
计算结果：14

> sqrt(16)
计算结果：4.0

> factorial(5)
计算结果：120

> sin(pi/2)
计算结果：1.0
```
